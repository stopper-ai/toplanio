# Toplanio

Community and event management SaaS.

This repository contains the collaborative development source for:
- Expo / React Native mobile app
- Community creation and member flows
- Supabase schema and migrations
- Dashboard design system handoff

Imported from the current Toplanio project workspace on 2026-10-01.

## Structure

- `mobile/` Expo / React Native application
- `design-kit/` shared dashboard components, design tokens and implementation guidance
- `docs/` product and architecture notes

## Collaboration

Use feature branches and pull requests for changes. Do not commit production secrets. Copy `.env.example` locally and keep real credentials in deployment environment variables.
